# Mongoose Wizard Project

This project is generated by Mongoose Wizard, https://mongoose.ws/wizard/
Mongoose Wizard is a visual Web dashboard builder for embedded devices.


This project is an example for creating a web file manager on embedded devices.
It works on Windows / Mac / Linux. In order to build it for any other
platform, import `mongoose/mongoose_wizard.json` file into
https://mongoose.ws/wizard/, choose your platform, generate project,
move and adjust an implementation from `main.c`.

See https://mongoose.ws/articles/building-a-web-file-manager-on-stm32-esp32-embedded-linux/
